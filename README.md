# Backlink Analyst Claude Skill

A free Claude Skill for planning, researching and managing backlink campaigns with or without SEMrush.

It helps marketers, founders, agencies and SEO professionals:

- Find relevant backlink prospects
- Research competitor link opportunities
- Choose the best pages to build links to
- Plan a balanced anchor text mix
- Create outreach emails and follow-up sequences
- Turn backlink data into a practical acquisition plan

## Install

1. Download this repository.
2. Copy the `backlink-analyst` folder into your Claude Skills directory.
3. Start a conversation about backlinks, off-page SEO, outreach or competitor links.

The skill will collect the missing site context and guide the analysis.

## Example requests

- Build a three-month backlink plan for my SaaS.
- Find resource-page prospects for this article.
- Compare my backlink opportunities with three competitors.
- Write a guest-post outreach sequence.
- Which page on my site should this backlink point to?
